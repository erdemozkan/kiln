All measurements

Where Kiln is slower

  • Loading from the cache: 1.8 s against 0.9 s for SmolLM2-135M. Kiln converts weights as it loads; transformers.js loads a pre-quantized file.
  • Download size: transformers.js's ONNX repos ship pre-quantized files, so a q4 model downloads less; Kiln downloads the original weights once and quantizes them.
  • Masked-LM logits through AutoModelForMaskedLM: 0.24 s against 0.11 s (transformers.js on WASM) for nine tokens, since Kiln computes them one position at a time. The fill-mask pipeline, which reads one position, is 2× faster.
  • The runtime itself is smaller: Kiln is 236 KB gzipped with its worker; transformers.js adds 6.7 MB of WASM.

Setup

  • An Intel Mac with Iris Plus Graphics 650 (an integrated GPU), Chrome. A modest GPU: discrete GPUs and Apple silicon are faster for both libraries.
  • On an Apple M3 (MacBook Air, Chromium), Kiln decodes SmolLM2-135M in q4 at about 307 tokens per second, against 59–74 on the Intel GPU; transformers.js was not measured there.
  • GPU clocks on this machine drift 10–15% between runs, so each pair was measured in one session.
  • The scripts and raw notes behind every row are in the repository README, with the outputs compared.
