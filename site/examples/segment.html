Cut out anything

Segment Anything: click an object in a photo to select it, then save it as a cutout.

SlimSAM-50, about 110 MB on first use

Click to add a point on the object; Shift-click a part that should be left out.

The code

const segmenter = await pipeline("mask-generation", "nielsr/slimsam-50-uniform");
// Points in the image's pixels; labels 1 = the object, 0 = not the object.
const masks = await segmenter(image, { points: [[450, 600]], labels: [1] });
// Three masks of different extent, each with the model's estimate of its quality.
const best = masks.reduce((a, b) => (b.score > a.score ? b : a));

The image is encoded once: further clicks on the same image run only the small mask decoder.
